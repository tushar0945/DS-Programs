# Data Structures and Algorithms in C++

This repository contains comprehensive implementations of core Data Structures and Algorithms in **C++17**.

## ?? Topics Covered
- **01. Arrays:** Search algorithms, Kadane's algorithm, Two-pointer techniques, Sliding window.
- **02. Sorting:** Bubble, Selection, Insertion, Merge Sort, Quick Sort, Heap Sort.
- **03. Strings:** Prefix algorithms, Anagram verification, KMP pattern searching.
- **04. Linked Lists:** Singly, Doubly, Circular Linked Lists, Cycle detection (Floyd's algorithm).
- **05. Stacks:** Stack ADT, Balanced Parentheses, Infix-to-Postfix conversion, Monotonic Stack.
- **06. Queues:** Circular Queue, Queue using Stacks, Deque, Sliding Window Maximum.
- **07. Binary Trees:** Inorder, Preorder, Postorder, Level-order BFS, Height & Diameter.
- **08. Binary Search Trees (BST):** Search, Insertion, Deletion, Validation, In-order successor.
- **09. Heaps & Priority Queues:** Min Heap, Max Heap, K-th Largest Element.
- **10. Graphs:** Adjacency List representation, BFS, DFS, Cycle Detection, Dijkstra, Kruskal MST.
- **11. Dynamic Programming:** 0/1 Knapsack, Coin Change, LCS, LIS, Matrix Chain Multiplication.
- **12. Greedy Algorithms:** Fractional Knapsack, Activity Selection, Huffman Coding.
